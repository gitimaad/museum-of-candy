# Museum of Candy

A fully responsive, multi-page promotional website for a fictional, interactive candy museum. This project is built using HTML5, custom CSS3, and the Bootstrap 4 framework to create a visually appealing, mobile-friendly user experience.

## 🍭 Features

*   **Responsive Design:** Utilizes the Bootstrap 4 grid system to ensure the layout looks great on all devices, from mobile phones to desktop monitors.
*   **Dynamic Navigation Bar:** Features a fixed-top navbar that seamlessly transitions its background color when the user scrolls down the page, implemented via jQuery.
*   **Multi-Page Layout:**
    *   **Home (`index.html`):** A landing page featuring striking typography, alternating image-text blocks, and a vibrant, candy-themed aesthetic.
    *   **About Us (`aboutus.html`):** Details the lore and immersive exhibits of the museum, including cascading cocoa waterfalls and a gummy bear sanctuary.
    *   **Tickets (`tickets.html`):** A dedicated ticketing portal (currently displaying a customized "Sold Out" notification).
*   **Custom Theming:** Uses a distinct pastel color palette (soft pinks, vibrant reds) and the "Nunito" Google Font to capture a whimsical, sugary vibe.

## 🛠️ Technologies Used

*   **HTML5:** Semantic page structure.
*   **CSS3:** Custom styling, masking effects, and media queries (`app.css`).
*   **Bootstrap 4.1.3:** CSS framework for grid layouts, typography, and responsive components.
*   **jQuery 3.3.1:** Used for the scroll-detection logic on the navigation bar.
*   **Google Fonts:** Specifically the [Nunito](https://fonts.google.com/specimen/Nunito) typeface.

## 🚀 How to Run Locally

Since this is a static frontend project, no complex server setup or build process is required.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/museum-of-candy.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd museum-of-candy
    ```
3.  **Open the app:**
    Simply open the `index.html` file in your preferred web browser.

## 📁 File Structure

*   `index.html` - The main landing page.
*   `aboutus.html` - The museum's story and exhibit details.
*   `tickets.html` - The ticket booking page.
*   `app.css` - Custom stylesheet containing color variables, typography overrides, and navbar scroll effects.
*   `/imgs` - Directory containing all the image assets (hands, milk, gumballs, sprinkles, etc.). *(Note: ensure your image assets are uploaded to this directory in your repo).*
